# 主角人设 —— 梦灵少女「星夜」

> 画风对标：`assets/image/artstyle-reference.png`

---

## 基本设定

- **身份**：被拉入梦境的少女，觉醒为"清醒梦者"，能夺取噩梦的攻击反打回去
- **性格**：安静但坚定，战斗时眼神锋利
- **体型**：小巧灵活，2头身卡通比例

---

## 外形

**头部**
- 齐刘海 + 蓬松外翘短发（到肩），深蓝渐变靛蓝（`#1A2B6B`→`#3D4FC7`），发梢带零星星光碎点
- 右侧鬓角一枚**星形发卡**（金色 `#FFE066`，常驻微光）—— 主要辨识特征
- 大圆眼，青白色瞳孔（`#80FFEC`），内有十字高光
- 瓷白肤色（`#FFF0E6`）

**服装**
- 宽松浅灰蓝短袖睡衣（`#B8C6DB`）+ 深灰蓝短裤（`#6B7FA0`）
- 设定是"睡觉时被突然拉进梦境"，所以穿的是睡衣+毛绒白拖鞋

**能力视觉**
- 双手掌心有青色光圈，夺弹时扩大发亮
- 子弹时间：全身笼罩半透明青色光膜

# 战斗机制设计文档

## 概述

BulletThief 的核心玩法：**夺取敌方子弹 → 转化为己方弹药 → 反击敌人**。围绕"子弹时间"这一核心能力，构建出**夺取 → 蓄积 → 释放**的循环节奏。

---

## 一、基础系统

### 1.1 移动

| 属性 | 值 |
|------|-----|
| 基础速度 | 280 px/s |
| 操作方式 | 触摸拖拽（1:1位移） / 键盘WASD |
| 边界 | 地图边距 28px + 角色半径 |

### 1.2 生命值

| 属性 | 值 |
|------|-----|
| 最大HP | 100 |
| 子弹时间内 | 无敌 |
| 受伤反馈 | 闪白 + 震屏 |

---

## 二、能量系统

| 属性 | 值 |
|------|-----|
| 最大能量 | 1.0（100%） |
| 初始能量 | 0.5 |
| 自然回复 | 0.06/s（可升级加成） |
| BT消耗 | 0.18/s |
| 开启阈值 | ≥ 0.25 |
| 退出冷却 | 1.5s（冷却期间不回复） |
| 擦弹回复 | 0.08 × 距离系数（越近越多） |

**能量循环**：回复能量 → 开启BT → 夺取子弹 → 能量耗尽 → 冷却 → 回复

---

## 三、子弹时间（Bullet Time）

### 触发

- 按住 BT 按钮（左手）且能量 ≥ 0.25
- 松开按钮或能量耗尽时结束

### 效果

| 层面 | 描述 |
|------|------|
| 时间缩放 | 敌方子弹/敌人速度 ×0.2 |
| 玩家射击 | 不受减速影响，保持全速 |
| 碰撞变为夺取 | 触碰敌方子弹 → 转为轨道子弹 |
| 无敌 | BT期间不受伤害 |
| 视觉 | 青色光膜 + 闪白 + 暗角 |

### 夺取机制

- 子弹时间内**接触**敌方子弹即夺取（需标记 `stealable`）
- 被夺取子弹生成轨道子弹，标记 `btShielded`
- `btShielded` 子弹在BT期间不可被常规射击消耗（保留给QTE）
- **BT结束时序**：① QTE窗口先消耗 `btShielded` 子弹 → ② QTE结束/超时后解除剩余子弹的 `btShielded` 标记

---

## 四、轨道子弹系统

### 4.1 轨道配置

| 属性 | 值 |
|------|-----|
| 基础半径 | 48 px |
| 每层间距 | 22 px |
| 每层容量 | 12 颗（可升级） |
| 旋转速度 | 2.4 rad/s |
| 归位速度 | 320 px/s（不受BT减速） |

### 4.2 被动伤害

- 轨道子弹旋转过程中碰到敌人直接造成伤害并消耗自身
- BT期间 `btShielded` 子弹跳过碰撞检测

### 4.3 颜色渐变

- 夺取时从暖色(敌方) → 冷色(己方)，0.33s渐变
- 夺取瞬间有闪白效果

## 五、发射系统

### 5.1 自动瞄准

| 属性 | 值 |
|------|-----|
| 锁定半径 | 180 px |
| 粘滞时间 | 0.15s（防抖动切换） |
| 无目标时 | 使用最后移动方向 |

### 5.2 射速档位（按持有子弹数量）

| 轨道子弹数 | 射击间隔 | 每次发数 | 散射角 |
|-----------|----------|---------|--------|
| ≤ 3 | 0.28s | 1 | 0° |
| ≤ 8 | 0.18s | 1 | 0° |
| ≤ 15 | 0.14s | 2 | ±10° |
| > 15 | 0.10s | 3 | ±14° |

- 子弹飞行速度：420 px/s
- 发射方式：按住发射键持续射击（首发立即响应）
- 弹源选择：从轨道中取最接近目标方向的子弹

### 5.3 撞击系统

- 玩家轨道子弹接触敌人时，前方 ±60° 扇形内的轨道子弹同时命中
- 伤害 = 命中子弹数 × 单发伤害

## 六、QTE 全弹爆发

### 触发条件

- 子弹时间**结束**瞬间
- 轨道中有子弹（`#orbitBullets > 0`）

### QTE 窗口

| 属性 | 值 |
|------|-----|
| 持续时间 | 1.5 秒 |
| 操作 | 按下发射键（提前按住不算，必须松手后新按下） |
| 视觉 | FIRE按钮上缩圈（从2.5倍半径缩至按钮边缘） + 角色身侧辅助环 |
| 成功 | 全弹爆发 |
| 失败/超时 | 子弹留在轨道正常使用 |

### 全弹爆发参数

| 属性 | 值 |
|------|-----|

| 速度倍率 | ×1.8 |
| 基础伤害倍率 | ×1.5 |
| 数量加成 | +0.12 × 弹数（10颗 → ×2.7） |
| 目标分配 | 按距离分配敌人，循环复用 |
| 反馈 | 闪白 + 震屏 |

## 八、核心战斗循环

```
┌─────────────────────────────────────────────────┐
│                                                 │
│  回复能量 ──→ 开启BT ──→ 夺取子弹（积蓄轨道）  │
│       ↑                          │              │
│       │                          ↓              │
│  击杀敌人 ←── 常规射击 ←── BT结束 → QTE窗口    │
│       │                                ↓        │
│       └──────────────── 全弹爆发（高伤清场）     │
│                                                 │
└─────────────────────────────────────────────────┘
```

**节奏设计**：
- BT是"蓄力阶段"——收集弹药，安全无敌
- BT结束是"释放窗口"——QTE成功 = 高伤清场，失败 = 正常输出也不亏
- 擦弹是"风险回报"——贴近敌弹但不进BT，快速回复能量

# 成长线机制设计（讨论稿 v2）

## 设计理念

### 独立成长线（非槽位替换）

每条成长线是**独立并行**的能力系统，可以同时点亮多条线路。不是互相替换，而是叠加/组合。局内升级选项来自已解锁的所有成长线，build 的多样性来自"这局侧重点哪条线"。

> "总有浪费的地方"——这没关系。和肉鸽/幸存者类游戏一样，并非所有升级都要完美协同，有些选择本身就是取舍。

### 双角色切换构想

灵感来源：角色名"星夜" → 联想《日之少年与夜之少女》的昼夜对偶。

**核心想法**：局内中段（首次Boss击杀后）解锁晨曦，两人可切换操控。共享HP和轨道弹，但能量条独立、BT内行为不同。

```
┌──────────────────────────────────────────────────────┐
│  星夜（夜/收集型）                                     │
│  - BT风格：时间冻结，接触夺取子弹→轨道环绕→射击/QTE  │
│  - 成长线：三轴（射击×轨道×QTE），48种组合             │
│  - 定位：远程射击、弹幕收集、控场                      │
├──────────────────────────────────────────────────────┤
│  晨曦（昼/消耗型）                                     │
│  - BT风格：时间冻结，碰敌强化斩击+子弹直接清除        │
│  - 成长线：两轴（BT斩击×收尾攻击），12种组合          │
│  - 定位：近战贴脸、爆发输出、清弹开路                  │
└──────────────────────────────────────────────────────┘
         ↕ 局内切换（CD 3~5s，共享HP/轨道弹）
```

**切换规则**：
- 切换有短CD（3~5s），防止无脑切
- 两人共享HP，但**能量条独立**（各自消耗/回复，互不干扰）
- 星夜后台自然回复能量；晨曦无自然回复（后台也不回）
- 轨道弹归属全局——晨曦可消耗轨道弹转化为自身能量
- 升级时两人各自的成长线独立出现在选项池中

**协作循环**：星夜攒弹（擦弹+夺取→轨道满）→ 切晨曦消耗弹（转化能量→强化斩击清场）→ 弹/能耗尽 → 切回星夜重新攒

> 详细设计见 `docs/CHARACTER_CHENXI.md`

---

### 成长线结构

```
┌─────────────────────────────────────────────────────────────┐
│  子弹时间框架（所有角色共享）                                 │
│  - 能量消耗 / 时间减速 / 无敌                                 │
│                                                             │
│  成长线 A ──┐                                                │
│  成长线 B ──┤── 同时生效，各自独立升级                        │
│  成长线 C ──┤   局内升级池 = 已解锁线路的并集                 │
│  成长线 D ──┘                                                │
└─────────────────────────────────────────────────────────────┘
```

- 成长线之间不互斥
- 同一次BT可以触发多条线路的效果（如同时有地雷+轨道）
- 升级资源各线独立，不存在"点了A就浪费了B"的问题

## 成长线 A：轨道射击（当前默认）

> 已实现基础版，见上方文档

| 阶段 | 行为 |
|------|------|
| BT内 | 接触夺取 → 子弹加入轨道环绕 |
| BT后 | 常规射击消耗轨道弹 / QTE全弹爆发 |

### 问题：常规射击太弱

当前常规射击 = "一颗一颗打出去"，手感单薄，和 QTE 爆发相比存在感低。
解决方案：**射击形态分支**——升级时可以选择将射击改变为不同形态。

### 射击形态分支（A线内部升级）

形态之间是**替换关系**（选了一个就定型，同一局只能走一条），给 A 线本身带来 build 差异。

#### 默认形态（未选分支时）

> 发射方式与 A-1 相同（单发/多发连射），但**无穿透、无弹速加成**。够用但不突出——选择任意分支都是对默认形态的明确强化。

#### A-1：流星坠夜（穿透速射）

| 属性 | 描述 |
|------|------|
| 核心 | 在默认射击基础上叠加——**飞行速度大幅提升** + 穿透，打出"一梭子贯穿"的爆发感 |
| 射速 | 快（间隔 0.08s），连射节奏紧凑 |
| 弹速 | 基础 ×2.5（从 420 → ~1050 px/s），瞬间命中感 |
| 穿透 | 子弹穿透敌人继续飞行（初始穿 2 个，可升级） |
| 视觉 | 拉长的青色弹丸+高速拖尾，命中时"突突突"连续打击感，不消失而是变暗穿透 |
| 适合 | 快速清线、精准输出、单列/走廊型敌群 |

**升级深化**：
- 穿透数 +1 / +2 / +3
- 每穿透一个敌人伤害不衰减（默认衰减 20%/个）
- 穿透尾端爆炸（最后一个穿透目标受 AOE）
- 弹速再提升（×3.0），超远距离瞬杀感

#### A-2：凝霜长吟（聚能激光）

| 属性 | 描述 |
|------|------|
| 核心 | 按住射击键不发射，改为持续消耗轨道弹充能激光条 |
| 输出方式 | 松开/充满后发射一道直线激光，持续 0.5~1.5s |
| 伤害 | 按消耗弹数计算（3颗=细光束，10颗=粗光柱） |
| 视觉 | 蓄力时轨道子弹向前方汇聚；激光为宽度可变的白-青光柱 |
| 适合 | 远距离精确击杀、Boss 弱点输出 |

**升级深化**：
- 激光宽度上限增加
- 蓄力速度加快（消耗弹药更快 = 更快满充）
- 激光末端折射（碰到边界反弹一次）
- 过充：超过 10 颗后继续蓄力 → 伤害指数增长但有过热风险

#### A-3：碎梦飞花（溅射弹幕）

| 属性 | 描述 |
|------|------|
| 核心 | 子弹命中敌人后爆裂为 3~5 颗小弹片向周围溅射 |
| 射速 | 中等（维持当前射速档位） |
| 溅射范围 | 爆裂半径 40~60px |
| 视觉 | 主弹命中后碎裂，小弹片扇形飞散 |
| 适合 | 密集敌群、AOE 清场 |

**升级深化**：
- 溅射弹片数 +2
- 弹片也能触发溅射（连锁一次，概率 30%）
- 溅射范围扩大
- 主弹命中时附加减速效果

#### A-4：霰雪惊鸿（散弹）

| 属性 | 描述 |
|------|------|
| 核心 | 每颗轨道弹发射时**分裂为 4~6 颗小弹丸**，扇形喷射，近距离高覆盖 |
| 射速 | 中等（间隔 0.22s），但每发即 shotgun 效果 |
| 射程 | 短（~180px 后消散），逼近才有效 |
| 穿透 | 小弹丸可穿透 1 个敌人（弥补短射程） |
| 弹丸大小 | 原子弹 ×0.4，密集但细小 |
| 视觉 | 发射瞬间"砰"一声散开，小弹丸带短拖尾扇形铺开，命中时多段跳字 |
| 适合 | 贴脸爆发、密集小怪群、近距离高DPS |

**为什么解决"子弹少时太弱"**：哪怕只有 1 颗轨道弹，发射也会分裂为 4~6 颗小弹——少量弹药也有覆盖感和打击反馈。

**升级深化**：
- 分裂数 +2 / +3（最高 9 颗/发）
- 射程延长（180 → 260px）
- 穿透数 +1（小弹丸穿 2 个敌人）
- 聚束模式（缩小散射角，提升单体集中伤害）
- 近距离加伤（距离 < 60px 时伤害 ×1.5，鼓励贴脸）

### 轨道形态分支（A线第二选择轴）

射击形态决定"子弹怎么打出去"，轨道形态决定"子弹怎么环绕/存在"。两者独立选择，组合出不同 build。

> **设计背景**：早期曾有轨道转速升级（超频转动），但实质是加速子弹消耗——转得越快撞敌越快消耗越快，收益为负（**已移除该升级**）。需要让轨道本身有不同的"存在方式"。

#### 默认轨道（未选分支时）

> 子弹环绕旋转，碰到敌人造成伤害并消耗自身（1次碰撞 = 消耗）。简单直接，无特殊效果。

#### O-1：环刃吟霜（刀刃轨道）

| 属性 | 描述 |
|------|------|
| 核心 | 子弹进入轨道后**变形为刀刃弹**，近战威力增强，碰撞 2~3 次才消耗 |
| 行为 | 碰撞敌人造成伤害（伤害 ×1.3），但不立即消耗，而是扣 1 耐久（初始 2~3） |
| 耐久 | 耐久归零后碎裂消失 |
| 视觉 | 子弹拉长变为菱形刀刃，碰撞时火花+微震，耐久低时刀刃裂纹发光 |
| 适合 | 贴脸战斗、延缓弹药消耗、配合散弹形态近战 build |

**为什么优于默认**：本质是"每颗子弹多撞几次"——同样数量的弹药能造成 2~3 倍被动伤害，解决了"转速越快消耗越快"的问题（现在转快 = 打得更多而不是浪费更快）。

**升级深化**：
- 耐久 +1（最高 4~5 次）
- 刀刃伤害倍率提升（×1.3 → ×1.8）
- 碎裂时爆炸（耐久归零最后一击 AOE）
- 刀刃击中减速敌人

#### O-2：潮汐寐息（脉冲轨道）

| 属性 | 描述 |
|------|------|
| 核心 | 轨道子弹周期性**向外脉冲扩张**，扩张时造成范围伤害后回收 |
| 行为 | 每 N 秒轨道半径从 48→120px 快速扩张再收回，经过的敌人受伤 |
| 消耗 | 每次脉冲消耗 1 颗子弹（弹药多时脉冲频率不变，但伤害按当前弹数算） |
| 视觉 | 轨道呼吸般膨胀-收缩，扩张时能量波纹向外扩散 |
| 适合 | 中距离节奏输出、周围敌人持续清理 |

**升级深化**：
- 脉冲频率加快（3s → 2s → 1.5s）
- 脉冲最大半径扩大
- 脉冲击退敌人（控场）
- 脉冲不消耗子弹（改为消耗少量能量）

#### O-3：繁星共语（共鸣轨道）

| 属性 | 描述 |
|------|------|
| 核心 | 轨道子弹越多，**每颗子弹的射出伤害越高**（全局倍率，按当前持有数计算） |
| 行为 | 碰撞正常消耗（同默认），但射出/碰撞时的伤害 = 基础伤害 × (1 + 弹数 × 0.08) |
| 10颗时 | 伤害 ×1.8；20颗时 ×2.6 |
| 视觉 | 弹数多时所有轨道子弹共振发光（越多越亮），射出时带光晕 |
| 适合 | 蓄力爆发型、鼓励"攒满再打"的节奏 |

**QTE 交互问题**：
> QTE 全弹爆发是快速逐颗射出——每射出一颗弹数-1，倍率随之下降。
>
> **方案 A（快照）**：QTE 触发瞬间锁定当前弹数作为倍率基准，整轮爆发都用这个值。简单暴力，QTE = 满倍率全弹输出，爽感最大。
>
> **方案 B（递减）**：逐颗递减。前几发超高伤，后面回归正常。有"先手一击最狠"的感觉，但总伤害低于方案A。
>
> **倾向方案 A**——QTE 本身就是奖励窗口，不需要再做惩罚。

**升级深化**：
- 倍率系数提升（0.08 → 0.12 / 0.15）
- 弹数 ≥ 15 时额外获得穿透
- "满载奖励"：弹数达到上限时自动触发一次全体闪光（对周围敌人造成一次伤害）
- QTE 时锁定倍率 +20% 额外加成

### QTE 形态分支（A线第三选择轴）

射击形态 = "平时怎么打"，轨道形态 = "子弹怎么存在"，QTE形态 = "爆发时怎么释放"。三者独立选择。

#### 默认 QTE（未选分支时）

> 当前版本：全弹逐颗快速射出（0.03s/颗），方向对准自动瞄准目标，速度 ×1.8，伤害 ×(1.5 + 0.12×弹数)。够爽但形式单一。

#### Q-1：长夜一矢（聚束炮）

| 属性 | 描述 |
|------|------|
| 核心 | 所有轨道弹**汇聚为一发巨型弹丸**，单次命中造成全部伤害 |
| 伤害 | 全弹总伤 ×2.0（集中比分散更高） |
| 弹体 | 体积按弹数缩放（10颗=中型，20颗=巨型），有碰撞判定面积 |
| 穿透 | 穿透所有敌人直到飞出屏幕 |
| 视觉 | 轨道弹急速螺旋汇聚→压缩→"砰"一声射出巨型光球，飞行路径上留下灼烧痕迹 |
| 适合 | 精英/Boss 斩杀、一条线上的敌群贯穿 |

> 设计理念："夺取子弹"本身就是蓄力过程——弹数越多，聚束炮越大。不需要额外的按住蓄力机制，QTE 保持单次触发即发射。

**升级深化**：
- 巨型弹命中后爆炸（终点 AOE）
- 飞行路径上的灼烧痕迹持续伤害 2s
- 弹体穿透时不衰减（默认每穿一个 -10% 伤害，升级后取消衰减）
- 弹数 ≥ 15 时自动附带引力效果（飞行路径吸附附近敌人）

#### Q-2：星坠如雨（全屏弹幕）

| 属性 | 描述 |
|------|------|
| 核心 | 所有轨道弹同时向**全方位360°**爆射，覆盖整个屏幕 |
| 分配 | 弹丸均匀分布在 360° 方向，每颗独立飞行 |
| 伤害 | 单颗伤害略低于默认（×0.8），但覆盖面极大 |
| 视觉 | 弹丸从玩家中心向四面八方炸开，像烟花爆炸 |
| 适合 | 被包围时、清屏、不需要瞄准 |

**升级深化**：
- 弹幕波数（爆射 2~3 波，每波间隔 0.2s）
- 弹丸飞行中分裂（每颗再分裂为 2 颗小弹）
- 击退效果（全方位推开所有敌人）

#### Q-3：群星各归（锁定齐射）

| 属性 | 描述 |
|------|------|
| 核心 | QTE 触发时自动**标记屏幕内所有敌人**，子弹分配后同时追踪命中 |
| 分配 | 按敌人血量比例分配弹数（血厚的多分几颗） |
| 命中率 | 100%（追踪弹，不可能 miss） |
| 伤害 | 单颗 ×1.2（略高于默认，因为保证全中） |
| 视觉 | 瞬间全屏闪光标记十字准星 → 子弹同时射出 → 各自拐弯追踪目标 → 同时命中 |
| 适合 | 散布在各处的残血敌人、保证不浪费弹药 |

**升级深化**：
- 标记时减速被标记敌人 0.5s（争取更多输出窗口）
- 超标记：每个敌人额外受 1 点固定伤害/标记数（标记多 = 额外伤害）
- 弹药溢出时（弹数 > 敌人数），多余子弹自动追踪场外即将进入的敌人

#### O-4：薄翼守梦（护盾轨道）

| 属性 | 描述 |
|------|------|
| 核心 | 轨道子弹获得**护盾值**，能额外抵挡敌方子弹（初始每颗抵挡 1 发） |
| 碰撞敌人 | **保留默认行为**——撞到敌人照常造成伤害并消耗自身 |
| 碰撞敌弹 | 额外能力——抵挡敌方子弹时扣护盾值而非消耗自身 |
| 护盾值归零 | 退化为普通弹（下次碰撞正常消耗） |
| 视觉 | 子弹外圈薄蓝光环（有护盾时），抵挡时闪白+光环碎裂变暗 |
| 适合 | 弹幕密集关卡的生存保障，但需要走位避免被敌人"蹭掉" |

**设计巧妙之处**：护盾弹仍然会因为碰到**敌人本体**而消耗（和默认一样），所以敌人贴脸时护盾根本留不住——你想保住防御层就得主动拉开距离，但拉远了又射不到。形成"安全距离 vs 输出效率"的走位博弈。

**升级深化（成长线方向）**：
- 每颗护盾值 +1（可抵挡 2→3→4 发敌弹）
- 抵挡时反弹小弹丸回击
- 护盾值恢复（每 5s 自动回复 1 点护盾值，不用重新夺取）
- 抵挡时回复少量能量

### 形态选择时机

```
局内首次 A 线升级：纯数值强化（+伤害/+轨道容量）
第 2~3 次 A 线升级：出现射击形态分支（四选一）
第 3~4 次 A 线升级：出现轨道形态分支（四选一）
第 4~5 次 A 线升级：出现 QTE 形态分支（三选一）
选定后：后续 A 线升级围绕已选形态深化
```

> 三个轴按先后顺序解锁，越晚解锁的轴影响越"大招化"。早期确定日常打法（射击），中期确定存活/积蓄方式（轨道），后期确定爆发高光（QTE）。

三轴独立选择，组合示例：
| 射击 | 轨道 | QTE | Build 风格 |
|------|------|-----|-----------|
| 流星坠夜 | 繁星共语 | 长夜一矢 | 攒满→高倍率巨型贯穿弹，一击毁灭 |
| 霰雪惊鸿 | 环刃吟霜 | 星坠如雨 | 近战刀刃+散弹，爆发时360°烟花清场 |
| 凝霜长吟 | 繁星共语 | 长夜一矢 | 蓄力流极致——平时攒弹蓄激光，QTE再来一发超级炮 |
| 碎梦飞花 | 潮汐寐息 | 群星各归 | 全覆盖 AOE build，QTE 精准收割残血 |
| 流星坠夜 | 薄翼守梦 | 群星各归 | 远程安全输出，护盾挡弹存活，QTE精准分配不浪费 |
| 霰雪惊鸿 | 环刃吟霜 | 星坠如雨 | 贴脸战士——刀刃延寿+散弹贴脸+360°清场保命 |

## 成长线 B：夺取范围增强（纯辅助）

> "扩大BT中的夺取判定半径，让收集更轻松"

### 概念

纯辅助型成长线——不改变夺取方式（仍需接触），但**扩大接触判定半径**，让玩家不必精确贴到子弹上也能夺取。降低操作精度要求，间接提升收集效率。

### 成长阶梯

| 等级 | 升级名 | 效果 | 数值 |
|------|--------|------|------|
| B1 | 梦境亲和 | 夺取判定半径扩大 | 判定半径 32px → 48px（+50%） |
| B2 | 引力共鸣 | 判定半径继续扩大 + 进入范围的子弹微量减速 | 半径 → 64px（+100%）；范围内子弹速度 ×0.85 |
| B3 | 星域吞噬 | 判定半径大幅扩大 + 范围内子弹自动偏转靠近 | 半径 → 96px（+200%）；子弹每帧向主角偏转 5° |

### 设计要点

- **纯辅助**：不增加伤害、不改变释放方式，只让"收集"这件事更容易
- **无 QTE 交互**：不影响 QTE，不消耗额外资源
- **与其他线叠加**：B 扩大的判定同样适用于 C（地雷放置）和 D（锚点定位）的夺取触发
- **3 级封顶**：辅助线不需要太深的成长，让升级资源留给 A/C/D 的战斗深化

### 视觉参考

```
B1：主角周围浅青色圆环微微脉动（提示判定范围）
B2：圆环变亮，范围内子弹带轻微减速拖尾
B3：圆环扩大明显，范围内子弹可见地弯曲轨迹靠近
```

## 成长线 C：梦境地雷

> "夺取时留下地雷，BT结束后爆炸"

### 概念

BT期间夺取子弹时，在被夺取子弹的**原位**留下一颗地雷。BT结束后（时间恢复流动），所有地雷同时引爆造成范围伤害。

### BT内行为

| 属性 | 描述 |
|------|------|
| 夺取方式 | 与A相同（接触夺取） |
| 额外效果 | 每次夺取有概率（60%）在原位留下地雷 |
| 地雷外观 | 暗紫色六角星标记，微微脉动 |
| 叠加机制 | 玩家经过已有地雷时，50% 概率叠加计数+1（每层 +10% 伤害，+2px 范围） |

### BT后释放

| 属性 | 描述 |
|------|------|
| 引爆时机 | BT结束后 0.3s 统一引爆（默认触发，无需QTE） |
| 伤害 | 基础 AOE 伤害 3 + 叠加层数加成（每层 +10%） |
| 范围 | 基础 60px 半径 + 每层 +2px |
| 连锁 | 地雷爆炸范围触及其他地雷时，该地雷伤害额外 +25% |

> **无 QTE 交互**：地雷引爆完全独立于 QTE 系统。QTE 只影响 A 线的射击爆发形态。

### 差异化设计点

- **优势**：控制区域、被动布场，适合"规划路线"的策略玩法
- **代价**：需要主动在敌人身边夺取才有意义（远离敌人的地雷可能炸空）
- **叠加设计**：拖拽移动很容易经过已有地雷，所以单层收益刻意压低（+10%/+2px），靠层数堆叠
- **升级方向**：地雷概率→100%、叠加上限、连锁倍率、引爆后留下减速区域

### 视觉参考

```
放置地雷：夺取子弹瞬间原位生成紫色六角脉冲
玩家经过叠加：地雷膨胀一下 + 数字+1浮出
BT结束引爆：先闪白0.1s → 同时爆炸（大小按叠加层数）→ 震屏
```

## 成长线 D：梦境连线

> "被夺取的子弹按顺序连线，BT结束后变成光束"

### 概念

BT期间夺取的子弹不再进入轨道，而是在原位留下"锚点"。锚点之间按夺取顺序自动连线。BT结束后，连线变为**持续伤害光束**，横切穿过的敌人受到持续伤害。

### BT内行为

| 属性 | 描述 |
|------|------|
| 夺取方式 | 接触夺取（同A） |
| 子弹去向 | 不进入轨道，在原位变为"锚点" |
| 连线 | 锚点之间按夺取顺序1→2→3…自动连线（虚线提示） |
| 视觉 | 锚点为青色光珠，连线为闪烁虚线 |

### BT后释放

| 属性 | 描述 |
|------|------|
| 触发 | BT结束后自动激活（默认触发，无需QTE） |
| 变化 | 虚线变为实线光束（持续 3s） |
| 伤害 | DPS = 2/s/段（锚点越密集线段越短，单位长度伤害越集中） |
| 光束宽度 | 默认 12px；相邻锚点距离 <80px 时加粗至 24px，DPS×1.5 |

> **无 QTE 交互**：光束激活完全独立于 QTE 系统。QTE 只影响 A 线的射击爆发形态。

### 差异化设计点

- **优势**：控制面积大，适合"划线切割"大量杂兵的爽快感
- **代价**：需要规划夺取路线（顺序 = 连线形状），乱夺 = 乱线 = 伤害分散
- **升级方向**：光束持续时间、光束宽度、锚点自动吸附附近子弹、光束消散时收束爆炸

### 视觉参考

```
BT中：每夺一颗子弹，锚点之间"嗖"一条虚线延伸
BT结束：虚线从起点到终点依次点亮为实线光束（0.2s/段）
光束存在期间：光束缓慢脉动，碰到敌人闪烁白光
```

## 多线叠加示例

> 独立成长线意味着一次BT可以同时触发多条线效果。以下是几个有趣的组合：

| 组合 | 效果描述 |
|------|---------|
| A+B | 扩大判定让夺取更轻松，轨道弹更容易攒满，QTE 大规模爆发 |
| A+C | 正常夺取进轨道，同时布雷；BT结束后先引爆地雷再射击残血 |
| A+D | 夺取时一部分进轨道一部分定锚；BT结束后光束切割+射击补刀 |
| B+C | 扩大判定让布雷覆盖更广，经过叠加更方便 |
| B+D | 扩大判定让定锚更密集（<80px），触发光束加粗加伤 |
| C+D | 夺取时既布雷又定锚；BT结束后地雷爆+光束切，双重清场 |

**冲突处理**：当同一颗被夺取的子弹涉及多条线（如A想进轨道，D想定锚）：
- 按优先级分配（具体比例后续测试调）
- 或按比例分配（如各50%）

## 双角色设计方向（备忘）

### 星夜（现有角色）

- 已有人设和视觉
- BT = 时间冻结（经典子弹时间）
- 定位：收集型、控场型、远程射击
- 成长线三轴：射击形态（流星坠夜/凝霜长吟/碎梦飞花/霰雪惊鸿）× 轨道形态（环刃吟霜/潮汐寐息/繁星共语/薄翼守梦）× QTE形态（长夜一矢/星坠如雨/群星各归）

### 晨曦（第二角色）

| 维度 | 设计 |
|------|------|
| 身份 | 梦境的"白日面"清醒梦者，星夜的对偶搭档 |
| 性格 | 开朗莽撞、先冲再想，战斗时表情兴奋 |
| 视觉 | 暖色系（金/琥珀橙），短发+淡绿短袖+黄围巾（详见 `CHARACTER_CHENXI.md`） |
| BT能力 | 同为时间减速，但BT内行为不同：强化斩击（碰敌爆出刀光）+ 子弹清除（直接销毁而非夺取） |
| 能量来源 | 无自然回复，完全依赖消耗轨道弹充能（星夜攒弹→晨曦消耗） |
| 解锁时机 | 局内首次Boss击杀后，剧情对话解锁（同局可用） |
| 切换CD | 3~5s |
| 成长线两轴 | BT斩击形态（无尽斩刑/断空弧刃/灼痕行路/万有引斩）× 收尾攻击形态（终幕·裁决/终幕·千刃/终幕·一闪）|

> 详细设计见 `docs/CHARACTER_CHENXI.md`

## 成长线解锁方式

采用**幸存者肉鸽**模式：

| 机制 | 说明 |
|------|------|
| 局内出现 | 升级时从已解锁的成长线池中随机刷出选项（三选一） |
| 局外解锁 | 部分成长线需要在局外永久解锁后才会进入池中 |
| 初始池 | A（轨道射击）默认可用 |
| 解锁条件 | 局外通关/成就/金币等（具体条件待定） |

> 和经典幸存者类游戏相同——你拥有的成长线越多，局内选项池越丰富，build 变化越多。但"拥有"不代表"必出"，依然有随机性和取舍。
