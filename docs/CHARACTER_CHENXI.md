# 第二角色人设 —— 晨曦

> 美术复用星夜绘制方法，换色 + 换锚点元素

---

## 基本设定

- **名字**：晨曦
- **身份**：梦境的"白日面"清醒梦者，星夜的对偶搭档
- **性格**：开朗莽撞、先冲再想，战斗时表情兴奋
- **体型**：与星夜相同（小巧灵活，2头身卡通比例）
- **解锁时机**：局内首次Boss击杀后，剧情对话解锁（同局可用）

---

**与星夜的区别一览**：

| 发卡 | 五角星（金色） | **小王冠**（银白色 `#E8E8F0`） |
| 瞳色 | 青白 `#80FFEC` | **琥珀橙** `#FFAA33`（内有十字高光） |
| 上衣 | 浅灰蓝睡衣 `#B8C6DB` | **淡绿色短袖** `#B8E6C8` |
| 下装 | 深灰蓝短裤 `#6B7FA0` | **白色短裤** `#F0F0F0` |

**能力视觉**：
- 斩击时双手出现橙金色弧形刀光
- BT内（强化斩击）：全身笼罩半透明金色光膜
- 清除子弹时：子弹被金光切碎消散

---

## 设计目的

**核心定位**：当玩家没有子弹时也有战斗能力。

星夜的输出完全依赖"有轨道弹" → 没弹 = 几乎无伤害。晨曦填补这个空窗期：

```
星夜轨道弹打完 → 切换晨曦 → 近战斩击输出
                              → BT清弹保命
                              → 积蓄/等待星夜轨道恢复
            ← 切回星夜 ← 有弹可用了
```

---

## 战斗机制

### 一、基础斩击（非BT状态）

| 属性 | 描述 |
|------|------|
| 触发方式 | **碰到敌人**即自动发动（不需按键） |
| 消耗 | 无消耗（基础能力） |
| 伤害 | **固定 1 点**（纯保底/过渡手段，不构成主要输出） |
| 频率 | 每个敌人有冷却（0.5s），防止贴着同一个敌人无限刷伤害 |
| 范围 | 以角色为中心的小范围弧形（约 ±60°前方，range=32） |
| 视觉 | 碰撞瞬间闪出金色弧形刀光 + 敌人微击退 |

> 注意：是"撞到怪物"触发，不是"怪物撞到你"。玩家需要**主动走位贴脸**。

### 二、强化斩击（BT状态内）

| 属性 | 描述 |
|------|------|
| 触发方式 | BT内碰到敌人时，自动升级为强化版 |
| 消耗 | **消耗能量**（每次强化斩击额外扣能量，如 0.05/次） |
| 伤害 | 高（基础斩击 ×2.5~3.0） |
| 范围 | 扩大（±90° 或全周） |
| 附加效果 | 击退距离增大、可能附带减速 |
| 视觉 | 更大更亮的金色弧光 + 斩击轨迹残留 0.3s |

**能量分段机制**：强化斩击的威力和消耗随能量段变化，形成"爆发→衰减"的自然曲线：

| 能量段 | 斩击等级 | 伤害倍率 | 每次消耗 | 体感 |
|--------|---------|---------|---------|------|
| >60% | **全力斩** | ×3.0 | 0.08 | 刚切换，火力全开 |
| 30%~60% | **常规强化** | ×2.0 | 0.05 | 稳定输出阶段 |
| <30% | **衰减斩** | ×1.3 | 0.02 | 快没了，准备撤退 |
| 0% | BT结束，基础斩击 | ×1.0 | 0 | 免费但弱 |

> BT减速效果全程不变（始终相同减速率），分段只影响斩击威力和消耗。

**倍率叠算规则**：最终伤害 = 基础斩击伤害 × **能量分段倍率** × **形态基础倍率**（乘算关系）。例如全力斩（×3.0）+ S-1（×1.2）= ×3.6。

**能量条上限**：1.0（满值），即百分比制。（具体"1.0对应多少秒BT时长"由消耗速率决定）

**节奏曲线**：蓄力越足→开场爆发越猛（高能量段消耗快但威力高）；低能量段消耗慢反而能多撑一会，给玩家留出收尾/切回的操作窗口。

**核心博弈**：全力斩阶段多砍 = 爆发高但BT更快进入衰减段。存能量少砍 = BT持续久但浪费了高倍率窗口。加上收尾攻击与斩击计数挂钩（见成长线），"多砍"还有额外收益。

### 三、子弹清除（BT状态内）

| 属性 | 描述 |
|------|------|
| 触发方式 | BT内碰到敌方子弹时 |
| 效果 | **直接清除**（不夺取、不加入轨道） |
| 消耗 | 无额外消耗（清除本身免费，BT时间才是成本） |
| 视觉 | 子弹被金色刀光切碎→粒子消散 |
| 与星夜的区别 | 星夜=夺取进轨道；晨曦=直接销毁 |

> 设计意图：晨曦不积蓄子弹，而是"清路"。帮星夜创造安全的环境，切回星夜后不会面对满屏弹幕。

## 能量系统

晨曦不射击 → 原"射击键"改为**手动充能键**（将轨道弹转化为能量）。

### 核心规则：转化轨道弹 = 唯一能量来源

| 属性 | 描述 |
|------|------|
| 自然回复 | **无**（晨曦没有自然能量回复） |
| 擦弹回复 | **无**（晨曦的定位是冲锋贴脸，不是灵巧闪避） |
| 能量来源 ① | **切换自动转化**：切到晨曦时自动消耗轨道弹回能，直到达到阈值（如 3~4 颗的量） |
| 能量来源 ② | **手动转化**：按住原"射击键"，逐颗消耗轨道弹回能（0.2s/颗） |
| 能量来源 ③ | **BT内清弹**：清除敌方子弹时回复少量能量（BT内续航手段） |
| 能量用途 | 维持BT（0.18/s） + 每次强化斩击消耗（如 0.05） |
| 无能量时 | 无法开BT，只能用基础斩击（免费但伤害低） |
| 轨道弹归属 | 未转化的继续环绕——"星夜还在场上" |

### 为什么没有自然回复

- **强化角色协作感**：晨曦的能量完全依赖星夜积攒的轨道弹，两人是"攒→消耗"的搭档关系
- **操作风格区分**：星夜靠擦弹/自然回复（灵巧型）；晨曦靠消耗弹药（激进型）
- **切换信号清晰**：没弹可转 + 能量空 = 该切回星夜了，不会"干等回复"
- **不会卡死**：基础斩击永远可用（免费），只是威力低。实在没能量也能战斗

### 操作节奏

```
切换到晨曦 → 自动转化3~4颗弹（立刻有能量）
  → 贴脸强化斩击 → 能量下降
  → 间隙按充能键手动追加 → 继续砍
  → 开BT → 清弹续能 + 强化斩击清场
  → 能量耗尽，没弹可转 → 切回星夜
```

## 与星夜的切换交互

| 规则 | 说明 |
|------|------|
| 切换CD | **无CD**（自由切换，能量/轨道弹资源本身就是限制） |
| 共享HP | 两人共用一条血条 |
| **独立能量条** | 两人各自有自己的能量条，互不干扰 |
| 轨道弹归属 | 全局共享——切到晨曦后轨道弹不消失 |
| BT机制 | 两人都能开BT（减速效果相同），但消耗各自的能量条，BT内行为不同 |

### 独立能量条对比

| 属性 | 星夜 | 晨曦 |
|------|------|------|
| 能量用途 | 维持BT | 维持BT + 强化斩击（分段消耗） |
| BT消耗 | 0.18/s | 0.18/s + 强化斩击（0.02~0.08/次，按能量段递减） |
| 回复方式 | 自然回复 0.06/s + 擦弹 | **无自然回复**。仅靠：转化轨道弹 + BT内清弹 |
| 后台行为 | 正常自然回复（非当前角色时） | **不回复**（没有自然回复源） |

**为什么独立**：
- 星夜 = 自给自足型（自然回复 + 擦弹），节奏平稳
- 晨曦 = 消耗型（只能"吃"轨道弹），爆发但有限
- 切换动机不同：星夜切晨曦 = "弹药够了，去输出"；晨曦切星夜 = "弹药/能量耗尽，回去攒"

**切换节奏设计**：

```
┌────────────────────────────────────────────────────────────┐
│ 星夜阶段（自给自足：自然回复 + 擦弹）                        │
│  回复能量 → 开BT → 夺取子弹填满轨道 → 射击输出 → 弹药耗尽   │
├────────────────────────────────────────────────────────────┤
│ ↓ 切换晨曦（轨道有存弹 = 晨曦有"燃料"可用）                 │
├────────────────────────────────────────────────────────────┤
│ 晨曦阶段（消耗型：吃轨道弹获得能量）                         │
│  自动转化3~4颗弹→有能量→强化斩击 → 开BT清弹续能+砍         │
│  轨道弹吃完 + 能量耗尽 = 无法继续                           │
├────────────────────────────────────────────────────────────┤
│ ↓ 切回星夜（去重新攒弹）                                    │
└────────────────────────────────────────────────────────────┘
```

> 核心协作："星夜攒弹 → 晨曦消耗弹"。晨曦的续航完全取决于星夜之前攒了多少轨道弹。切换不是"等回复"，而是"有资源就去花"。

## 晨曦的成长线

晨曦的升级来自同一个局内升级池，解锁晨曦后出现其专属升级选项。

### 构建轴：BT斩击形态 × 收尾攻击形态

星夜是三轴（射击×轨道×QTE），晨曦是**两轴**：

```
BT斩击形态（四选一） × 收尾攻击形态（三选一）
```

> 星夜的轨道形态在晨曦阶段依然生效（环绕方式/弹属性不变），无需额外对标一轴。
> 晨曦两轴 = 12种组合，比星夜的48种更精简，符合"爆发消耗型"的直觉定位。

**形态选择时机**：与星夜相同——在局内固定升级里程碑时弹出形态选择（从可选池中选一），选定后该轴锁定形态，后续升级只加深该形态等级（Lv1→Lv4）。斩击形态（轴一）和收尾形态（轴二）分别在不同里程碑解锁选择。

---

### 轴一：BT斩击形态（四选一）

BT期间强化斩击的行为变体。基础框架不变（碰敌触发、能量分段），但附加效果不同。

**斩击视觉基础**：碰到敌人后，在敌人身上爆出一道两端尖中间粗的弧形刀光。这道刀光本身也有伤害判定（小范围，可波及紧邻的其他敌人）。不是从自身发射，而是"在命中位置爆开"。

**设计原则**：
- 每种形态改变的是"如何砍"而非"砍不砍"
- 都适用能量分段机制（全力斩/常规/衰减的倍率照常生效）
- 各有适合的场景，无绝对上下位
- **单体/群体倍率差异**：单体形态基础伤害更高，群体形态单次低但覆盖面大

#### 基础倍率差异

| 形态 | 定位 | 基础斩击倍率 | 说明 |
|------|------|-------------|------|
| S-1 无尽斩刑 | 单体 Boss杀手 | ×1.2 | 单次伤害最高 |
| S-2 断空弧刃 | 半径延伸 | ×1.0 | 标准值，靠剑气补充 |
| S-3 灼痕行路 | 群体区域 | ×0.8 | 单刀弱但路径持续补伤 |
| S-4 万有引斩 | 群体聚怪 | ×0.85 | 单刀略弱但聚怪后连砍效率高 |

---

#### S-1：无尽斩刑（连击递增）— Boss杀手

连续命中同一敌人时伤害递增，鼓励贴脸单体。

| 等级 | 名称 | 效果 | 数值 |
|------|------|------|------|
| Lv1 | 初试锋芒 | 连续命中同一敌人伤害递增 | 第1刀×1.0 → 第5刀×1.8，5刀满 |
| Lv2 | 刑不可断 | 连击窗口延长 + 上限提升 | 断连容忍 1.5s→2.5s；上限×1.8→×2.2 |
| Lv3 | 十连斩诀 | 满连击不重置 + 切目标保留 | 达到上限后维持最高倍率不重置；切换目标2s内保留计数 |
| Lv4 | 万斩归一 | 满连击后附带"破甲印记" | 连续5刀后目标获得破甲印记：后续所有伤害+25%，持续4s，可刷新 |

**满级体感**：贴着Boss连砍，倍率快速拉满后锁定×2.2，同时破甲让星夜切回来射击也享受加伤。

---

#### S-2：断空弧刃（飞斩剑气）— 远程延伸

刀光在敌人身上爆开后，额外沿方向射出一道剑气，使贴脸近战也能打到后排。

| 等级 | 名称 | 效果 | 数值 |
|------|------|------|------|
| Lv1 | 初弦一刃 | 斩击碰敌后射出剑气 | 射程 2 身位，宽度窄，伤害 = 斩击×0.6 |
| Lv2 | 长弦远刃 | 射程+宽度提升，可穿透 | 射程 4 身位，宽度+50%，穿透1个敌人 |
| Lv3 | 裂空双刃 | 每次斩击射出 2 道剑气（V字形） | 双剑气±15°扩散，各自独立穿透 |
| Lv4 | 断空无尽 | 无限穿透 + 命中留减速痕 | 所有剑气无限穿透；命中敌人减速30%持续1.5s |

**满级体感**：贴脸砍一刀 → 两道剑气飞出穿透整排敌人并减速，近战也有远程清线能力。

---

#### S-3：灼痕行路（路径伤害）— 区域控制

碰敌正常斩击，额外在BT移动路径上留下伤害带。**灼痕在BT期间冻结保留，BT结束后统一开始倒计时**——此时敌人恢复全速，灼痕的减速和伤害才真正发挥控场价值。

| 等级 | 名称 | 效果 | 数值 |
|------|------|------|------|
| Lv1 | 灼行初迹 | BT内移动路径留伤害带，BT结束后持续存在 | 宽度 20px，**BT后持续3s**，DPS 2 |
| Lv2 | 焦土蔓延 | 路径加宽 + BT后持续延长 + DPS提升 | 宽度 32px，**BT后持续4.5s**，DPS 3 |
| Lv3 | 灼原减速 | 灼痕上的敌人被减速 + 受晨曦所有伤害加成 | 减速35%；在灼痕上受**晨曦所有伤害**+30%（含基础斩击、强化斩击、收尾攻击） |
| Lv4 | 业火回廊 | BT后持续时间大幅延长 + 路径交叉处引爆 | **BT后持续7s**；路径交叉点产生爆炸（半径40px，伤害=DPS×3） |

**时间线**：
```
BT开启 → 边跑边砍，路径不断生成（全部冻结保留）
BT结束 → 所有灼痕同时"点燃"，开始倒计时
       → 敌人恢复全速，踩进灼痕被减速35%+持续烧伤
       → Lv4时交叉点爆炸清场
       → 倒计时结束，灼痕消散
```

**满级体感**：BT里疯狂穿行画出复杂路径 → BT结束后整个场地变成7秒的"火焰迷宫"，交叉点不断爆炸，敌人被困在里面减速挨打。给星夜创造了一个极其安全的射击窗口。

---

#### S-4：万有引斩（吸附聚怪）— 聚怪连招

斩击附带范围吸引效果，将周围敌人拉向自身，利于聚怪后连砍。配合密集怪群让刀光爆开波及更多目标。

| 等级 | 名称 | 效果 | 数值 |
|------|------|------|------|
| Lv1 | 引力微澜 | 斩击附带小范围吸引 | 吸引半径 1.5 身位，力度弱 |
| Lv2 | 引力坍缩 | 吸引力增强 + 碰撞伤害 | 半径 3 身位；被吸引互撞的敌人受少量伤害（每对碰撞 = 斩击×0.2） |
| Lv3 | 质量囚笼 | 吸引中心产生滞留区 | 被吸到中心的敌人定身0.4s；定身结束小爆炸（半径30px，斩击×0.5） |
| Lv4 | 万有奇点 | 吸引范围大幅扩展 + 密度爆发 | 半径 5 身位；聚集≥4个敌人时自动触发"奇点坍缩"——全部受一次斩击×2.0 AOE + 击飞散开 |

**满级体感**：冲进怪群一砍 → 周围敌人全被吸过来 → 定身 → 奇点爆发炸飞 → 再冲下一群。节奏感极强。

### 轴二：收尾攻击形态（三选一）

BT结束瞬间触发的爆发攻击。**威力与BT期间的斩击计数直接挂钩**（封顶30次，超过不再增加收尾威力）。

| 形态 | 名称 | 效果 | 计数关系 |
|------|------|------|---------|
| F-1 | **终幕·裁决**（范围爆破） | BT结束瞬间以自身为圆心释放范围爆炸 | 计数越多 → 半径越大、伤害越高 |
| F-2 | **终幕·千刃**（回旋追踪） | 释放回旋刀，追踪分配给存活敌人 | 计数 = 回旋刀数量（全部集中在存活敌人上） |
| F-3 | **终幕·一闪**（贯穿冲击） | 向前方释放穿透冲击波 | 计数越多 → 冲击波越宽越远 |

**F-2 终幕·千刃补充说明**：
- 回旋刀数量 = BT内总斩击次数（如砍了15刀 = 15把回旋刀）
- 分配逻辑：智能分配在**存活**的敌人身上（Lv3后优先残血目标）
- 对Boss的效果：如果只有Boss一个存活目标 → 所有回旋刀集中命中 = 巨额爆发
- 对怪群的效果：分散收割多个残血小怪
- 视觉：金色回旋刃从角色身上飞出，各自追踪目标后命中爆散

**收尾攻击的博弈**：
```
想要强收尾 → BT内拼命多砍 → 能量掉得更快 → BT时间更短
保守少砍   → BT维持久     → 但收尾攻击弱
```
这与能量分段形成双重张力：高能量段本身倍率高（奖励多砍），但多砍也意味着更快进入低倍率段。

---

#### F-1：终幕·裁决（范围爆破）

以自身为圆心的 AOE 爆炸，计数越多半径和伤害越高。定位"冲入怪群砍完后的清场收尾"。

| 等级 | 名称 | 效果 | 数值 |
|------|------|------|------|
| Lv1 | 裁决初震 | BT结束时释放圆形爆炸 | 基础半径 = 1.5身位 + 计数×0.05身位；伤害 = 基础×(1 + 计数×0.06) |
| Lv2 | 裁决扩震 | 半径缩放提升 + 爆炸附带击退 | 半径缩放×1.4；爆炸将敌人击退1.5身位 |
| Lv3 | 裁决余波 | 爆炸后留下持续伤害区域 | 爆炸区域保留3s，每0.5s造成爆炸伤害×15%的余烬伤害 |
| Lv4 | 裁决轮回 | 计数≥20时触发二段爆炸 | 首段爆炸后0.8s，在同位置触发第二次爆炸（伤害=首段×0.7，半径×1.2）；二段也留余波 |

**满级体感**：BT猛砍30刀 → 结束瞬间巨大爆炸清空近身 → 0.8s后二次爆炸收割残血 → 余波持续烧3s。冲进怪堆砍完直接炸平。

---

#### F-2：终幕·千刃（回旋追踪）

回旋刀数量=斩击计数，追踪存活目标。对Boss集中打出巨量单体伤害，对怪群分散收割。

| 等级 | 名称 | 效果 | 数值 |
|------|------|------|------|
| Lv1 | 千刃散射 | 释放回旋刀追踪存活目标 | 每把回旋刀伤害 = 基础斩击×0.4；随机分配 |
| Lv2 | 千刃集束 | 回旋刀命中同目标时伤害递增 | 同目标每多命中一把，后续+8%伤害（第10把≈+72%） |
| Lv3 | 千刃穿心 | 回旋刀命中后爆炸 + 优先集中残血目标 | 每把命中后半径0.5身位小爆（×0.3溅射）；智能分配：HP<30%的目标被优先指派 |
| Lv4 | 千刃归一 | 计数≥15时解锁"终刃"：所有刀收束后合为一击 | 全部回旋刀命中后，0.5s汇聚为一把巨刃追踪HP最高的目标，伤害=所有回旋刀总伤×0.4的额外一击 |

**满级体感**：30把回旋刀飞出 → 智能分配收割小怪 → 集中在Boss身上递增爆炸 → 最后合体为终刃再补一记重击。对Boss的单体爆发最强。

---

#### F-3：终幕·一闪（贯穿冲击）

向前方释放穿透冲击波，计数越多越宽越远。定位"定向清线/走廊清扫"。

| 等级 | 名称 | 效果 | 数值 |
|------|------|------|------|
| Lv1 | 一闪初斩 | 前方释放穿透冲击波 | 宽度 = 1身位 + 计数×0.03身位；射程 = 3身位 + 计数×0.1身位；伤害 = 基础×(1 + 计数×0.05) |
| Lv2 | 一闪长驱 | 射程提升 + 冲击波减速 | 射程缩放×1.5；命中敌人减速40%持续2s |
| Lv3 | 一闪三连 | 释放3道扇形冲击波（前方±15°） | 3道冲击波各自独立穿透；中间那道伤害×1.0，两侧×0.7 |
| Lv4 | 一闪·终途 | 冲击波尽头产生横向斩线 | 冲击波到达最远端时，横向展开垂直斩击（宽度=冲击波射程×0.6），形成"T字形"清扫；斩线伤害=冲击波伤害×0.5 |

**满级体感**：BT结束 → 三道扇形冲击波飞出贯穿全场 → 到达终点横向展开斩线形成T字 → 大半个屏幕都被扫到。适合走廊地形和线性怪潮。

### 被动升级池（通用成长）

不设独立轴，在局内升级池中以普通权重出现。**基础斩击不做独立成长轴**——定位是保底/过渡手段（固定1点伤害），不应强到削弱BT的意义。

| 升级 | 效果 | 说明 |
|------|------|------|
| 基础斩击范围 | ±60° → ±90° | 非BT贴脸更容易命中 |
| 基础斩击冷却 | 0.5s → 0.3s | 提升非BT的过渡频率（伤害仍固定1点） |
| 充能效率 | 每颗弹转化量 +25% | 加速进入BT |
| 清弹回能 | 清弹回能 +50% | BT内续航更久 |
| 分段阈值下移 | 全力斩阈值 60%→50%，常规段 30%→20% | 高倍率窗口更长 |
| 收尾攻击基础伤害 | 单把回旋刀/爆炸基伤 +30% | 直接提升收尾质量 |
| 斩击计数加速 | 每次斩击计数 ×1.5（四舍五入） | 用更少的砍数堆出更强的收尾 |
