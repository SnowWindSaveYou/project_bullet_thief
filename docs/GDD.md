## 一、游戏概述

类幸存者游戏。玩家在被敌人包围的战场上生存，核心特色是**子弹夺取机制**：通过消耗能量开启子弹时间，在无敌状态下夺取敌方子弹，将其转化为环绕自身旋转的武器，再以撞击或发射的方式反打敌人。

**核心体验目标**：从被动挨打到反客为主的爽快感，以及通过积累轨道子弹产生的视觉压迫力。

## 二、视觉风格

### 2.1 总体风格

矢量图形 + 斜方向投影（Oblique Projection）。

- 所有元素均为几何矢量图形，无贴图
- 场景整体呈现斜45度投影视角，物体具有向右下方偏移的阴影，营造轻量3D空间感
- 深色背景，亮色发光元素，粒子效果突出

### 2.2 投影规范

```
实体本身（亮色）
    ↘ 偏移方向（右下，角度约45度）
阴影（深色半透明填充，无描边）
```

- 投影偏移距离与物体高度正相关
- 地面物体：阴影紧贴，偏移小
- 高空物体（如飞行中的抛物线子弹）：阴影与实体分离明显

### 2.3 颜色语言

| 元素 | 颜色规范 |
|------|---------|
| 玩家 | 白色主体，青色描边 |
| 普通敌人子弹（可夺取） | 暖色系（橙红），实心圆 |
| 子弹时间内可夺取状态 | 高亮轮廓闪烁，表示"可以被夺取" |
| 夺取后轨道子弹 | 冷色系（青/白），外发光描边；颜色切换时有短暂闪烁过渡 |
| 激光（不可夺取） | 深红色光束，蓄力阶段有粒子聚集效果 |
| 抛物线子弹（不可夺取） | 暗黄/深橙，形状与普通子弹明显不同（如菱形） |
| Boss专属子弹（不可夺取） | 黑色带红色描边，视觉气质危险 |
| 能量环 | 玩家周身圆弧，满能量时青色，消耗时逐渐变暗变短 |

### 2.4 抛物线子弹的高度表达

利用斜方向投影天然表达子弹高度：

```
飞行中：
  [子弹实体]（位置偏高，持续向落点移动）
      ↓ 较大间距
  [地面阴影]（持续移向落点，带预警圆圈）

落地瞬间：
  实体与阴影重合 → 触发AOE爆炸多边形扩散动画
```

玩家通过阴影位置判断落点，通过实体与阴影间距判断子弹当前高度（间距越小越快落地）。

## 三、操作方案

| 操作 | 手机 | 鼠标/PC |
|------|------|---------|
| 移动 | 拖动屏幕空白区域 | 按住左键拖动 / WASD |
| 开启/关闭子弹时间 | 左侧按钮 | 键盘 `Shift` |
| 发射轨道子弹 | 右侧按钮按住，松手停止 | 右键/空格按住，松手停止 |

### 发射方向逻辑（自动瞄准）

- 按住发射键时，玩家**不停止移动**（可边跑边射）
- 发射方向由**自动瞄准系统**决定：
  - **锁定范围内有敌人** → 自动瞄准最近的敌人
  - **锁定范围内无敌人** → 使用玩家最后的移动方向
- 锁定范围以玩家为中心的白色虚线圆环显示
- 锁定目标切换有 0.15s 粘滞时间，防止方向抖动
- 轨道子弹旋转到接近目标方向时，顺滑转向并射出
- 松开发射键，停止发射，剩余子弹继续环绕
- 子弹越多，短时间内打出的弹数越多（子弹陆续经过目标方向时依次射出）

### 设计意图

- 近处有小怪时自动清理，无需手动瞄准，不打断移动节奏
- 远处目标（Boss等）通过"朝它方向移动再射"来间接控制发射方向
- 心智模型统一：近处自动解决，远处"跑向哪打向哪"

## 四、能量系统

### 4.1 能量获取

| 来源 | 获取量 |
|------|--------|
| 时间自然恢复 | 持续缓慢回复 |
| 擦弹（子弹从玩家附近极近距离飞过，未命中） | 每次擦弹获得一定量，越近越多 |

### 4.2 子弹时间的能量规则

- 开启子弹时间需要达到**最低能量阈值**（避免频繁抖动）
- 开启后能量持续消耗，耗尽后自动退出子弹时间
- 退出后有**短暂冷却期**，冷却期内无法再次开启（能量需恢复至最低阈值以上）

### 4.3 能量条视觉

玩家身体外围的圆弧型光环：
- 满能量：完整圆圈，青色发光
- 消耗中：弧长缩短，颜色渐暗
- 低于开启阈值：颜色变灰，有视觉提示
- 冷却期：微弱闪烁，表示不可用

## 五、子弹时间机制

### 5.1 效果

- 玩家进入**无敌状态**
- 游戏整体不减速（玩家与敌人均正常运动），只是玩家无敌且可夺取子弹
- 碰触到的可夺取子弹被玩家吸收，变为轨道子弹

### 5.2 夺取判定

- 子弹飞行中与玩家碰撞体接触即触发夺取
- 夺取动画：子弹颜色切换（暖→冷），短暂闪烁，然后弯曲飞入轨道

### 5.3 轨道子弹

- 夺取后的子弹在玩家周围环绕旋转
- **无数量上限**（子弹积累是给玩家的爽点）
- 子弹较多时自动分层（内圈/外圈），防止视觉过于混乱
- 子弹时间结束后，轨道子弹**保留**，持续环绕直到被消耗

## 六、轨道子弹的使用

### 6.1 撞击（近战）

- 玩家移动时身体直接接触敌人触发撞击
- 撞击瞬间，轨道上处于**玩家与敌人之间扇形范围**内的所有子弹同时命中该敌人
- 子弹越集中在冲击方向，命中数越多，形成技巧空间（玩家会下意识控制撞击时机）

### 6.2 发射（远程）

- 详见操作方案 §三
- 所有经过目标方向的子弹依次顺滑转向发射
- 随时可停，灵活控制输出节奏

## 七、子弹类型

### 7.1 可夺取子弹

普通敌人发射，进入子弹时间后可被夺取。

具体属性（子弹类型）由肉鸽升级决定，基础形态为圆形。

### 7.2 不可夺取子弹

| 类型 | 来源 | 特征 | 应对方式 |
|------|------|------|---------|
| 激光 | 特殊敌人/Boss | 蓄力前摇明显（粒子聚集效果），线形攻击，持续伤害 | 提前横向躲避 |
| 抛物线炮弹 | 特殊敌人/Boss | 有飞行弧线，地面有阴影预警圈，落地AOE爆炸 | 观察阴影离开落点区域 |
| Boss专属子弹 | Boss | 弹型/颜色与普通子弹明显不同，视觉上传达危险感 | 纯躲 |

子弹时间内，不可夺取子弹依然保持危险视觉（不高亮、不闪烁），玩家可直观区分。

## 八、敌人设计

### 8.1 普通敌人

- 不同形状对应不同攻击模式（射击频率、弹速、弹型）
- 全部发射可夺取子弹
- 可能包含激光/抛物线攻击作为特殊技能的普通精英敌人

### 8.2 Boss

- 同时具备**可夺取普通子弹**和**不可夺取特殊攻击**
- 设定层面：Boss不知道玩家能夺取子弹，普通子弹只是其攻击组合的一部分
- 血量下降时增加不可夺取攻击比例（Boss受伤后本能升级攻击手段，非针对夺取机制的反制）
- 濒死阶段大量召唤小怪

### 8.3 Boss战的战术张力

召唤的小怪带来两难选择：
- **消灭小怪**：战场安全，但失去子弹来源
- **保留小怪**：危险升高，但可持续补充轨道子弹

对应肉鸽升级可以强化其中某一策略路线。

## 九、肉鸽升级方向

三个升级树，对应三种玩法风格：

| 升级树 | 方向 | 代表效果 |
|--------|------|---------|
| 轨道子弹强化 | 偏进攻爆发 | 轨道子弹伤害/穿透/元素效果 |
| 子弹时间强化 | 偏持续续航 | 能量效率/夺取范围/夺取速度 |
| 通用效果 | 偏辅助连锁 | 撞击范围扩大/发射穿透/连锁弹 |

升级由**用轨道子弹击杀敌人的数量**驱动，详见 §十。

## 十、地图与进程结构

### 10.1 地图形态

- **有边界封闭地图**（与拖动移动操作匹配）
- 敌人从地图四周边缘持续涌入
- 边界会形成自然压迫感，配合子弹时间的无敌特性，玩家可主动冲入包围圈夺取子弹、打出突围缺口

### 10.2 进程驱动：击杀积分制

升级和Boss触发均由**用轨道子弹击杀敌人的次数**驱动（普通击杀不计入）：

```
用轨道子弹击杀 → 积累击杀计数 → 到达里程碑 → 升级 / Boss出现
```

- 激励核心玩法：打得越激进，升级越快
- 保守打法升级慢，但玩家选择空间保留

### 10.3 里程碑参考（待数值调优）

| 里程碑 | 事件 |
|--------|------|
| 每隔 ~150 击杀 | 出现升级选择界面，短暂暂停刷怪 |
| ~500 击杀 | 第一个 Boss |
| ~1200 击杀 | 第二个 Boss |
| ~2000 击杀 | 终局 Boss / 通关 |

升级次数约 4-6 次（15-20 分钟内达到终局）。

### 10.4 单局节奏目标

- 单局目标时长：**15-20分钟**
- 每次升级界面提供 **3选1**
- 游戏整体压力随时间持续提升（刷怪频率、敌人种类）

## 十一、玩家生命值

- 玩家拥有**血量**，受伤不会一击必死
- 受伤来源：被敌方子弹直接命中（非子弹时间状态下）
- 血量 UI 位于**屏幕左上角**
- 普通敌人**不显示血条**，Boss 显示血条（屏幕底部或 Boss 头顶，待定）
- 肉鸽升级中可加入血量相关选项（上限提升、受伤回能等）

## 十二、视觉反馈规范

### 12.1 跳字风格：仿小丑牌（Balatro）

所有战斗数字反馈（伤害、得分、能量获取等）均采用 **Balatro 风格跳字动效**：

**4段动画时序**：
```
Phase 1 (0~15%)  : easeOutElastic 弹出，scale 0 → 2.0，快速淡入
Phase 2 (15~30%) : easeInQuad 回弹，scale 2.0 → 1.0
Phase 3 (30~75%) : sin 微浮动 + 数字滚动效果
Phase 4 (75~100%): 向上飞出 + 淡出 + 运动拖影
```

**文字渲染（4层叠加）**：
```
层1：同色系深影（右下偏移 2.5, 3.5）
层2：同色系内描（右下偏移 1.0, 1.5）
层3：主色
层4：白色高光（左上偏移 -1.0, -1.5）
```

**行动飘字（逐字错时）**：用于关键事件提示（如"子弹时间！"），每字延迟 55ms 弹入，附带背景光晕。

**代码来源**：`scripts/lib/VFX.lua`（`spawnPopup` / `spawnBanner`），依赖 `scripts/lib/Tween.lua`

### 12.2 画风参考

参考图：`assets/image/artstyle-reference.png`

- 深色调背景（深蓝灰）
- 元素轮廓清晰，色彩饱和度高
- 矢量几何风，搭配斜方向投影

## 十三、道具掉落系统

敌人击杀后概率掉落道具，玩家走近自动拾取。

### 13.1 基础道具类型

| 道具 | 效果 | 视觉 |
|------|------|------|
| 金币 | 积累用于升级界面消费（待定）或纯分数 | 小圆形，金黄色，斜投影 |
| 磁铁 | 短时间内自动吸附附近金币/道具 | U形矢量图，蓝色 |
| 治疗 | 恢复一定血量 | 十字形矢量图，绿色 |
| 充能 | 立即恢复一定能量（加速子弹时间可用） | 闪电形矢量图，青色 |

### 13.2 掉落规则

- 普通敌人：低概率掉落金币或充能
- 精英敌人：较高概率掉落，可能出现磁铁/治疗
- Boss：必定掉落升级选择 + 可能掉落稀有道具
- 道具在地图上存在一定时间后消失（防止地图被堆满）

### 13.3 道具视觉规范

- 所有道具图标使用 NanoVG 矢量绘制，禁止 emoji 替代
- 掉落时播放弹出动画（小跳弹），停止后轻微漂浮
- 玩家进入拾取范围时高亮描边
- 即将消失时闪烁提示

## 十四、资源规范

### 14.1 视觉资源约束

| 类别 | 规范 |
|------|------|
| 粒子效果 | 必须使用矢量图（NanoVG 程序化绘制）或贴图素材，禁止用 Unicode 字符代替 |
| 道具图标 / UI 图标 | 必须使用矢量图，禁止 Unicode emoji |
| 游戏内视觉元素 | **全面禁止 Unicode 字符**（⏱️ 🧲 🛡️ 等），所有视觉元素使用原创矢量图形或贴图 |
| **游戏 UI / HUD** | **所有 UI 界面（血条、能量环、升级选择、按钮等）必须使用 raw NanoVG 绘制**，禁止使用 urhox-libs/UI 组件系统，以实现完全自定义的动效（Tween 驱动的进入/退出动画、颜色渐变等） |

> 检查清单：代码中出现 emoji 或非 ASCII 字符作为视觉元素时，必须替换为 NanoVG 绘制的图形。
> 检查清单：所有 UI 元素（HUD、菜单、按钮、血条）必须通过 NanoVGRender 事件中的 raw NanoVG API 绘制，不得使用 UI.Panel / UI.Label 等组件。

### 13.2 音效设计

**BGM**
- 风格：J-Pop 或 Kawaii Future Bass
- 节奏：BPM 140-160，明快活泼

**配音（简短音效性质）**

| 场景 | 台词 |
|------|------|
| 游戏开始 / 状态激活 | "Let's Go!" |
| 击杀 / 得分 | "Yay!" |
| 受伤 / 失败 | "Oops!" |

**SFX 列表**

| 音效 | 描述 |
|------|------|
| 奔跑 | 轻微像素风脚步声 |
| 子弹夺取 | 清脆"咻"声，每次夺取触发，多次连续夺取可叠音 |
| 连续击杀 | 风铃声 / 加分音效，音调随连击数逐级升高 |
| 单次击杀 | 悦耳短促音效 |
| 受伤 | 低沉破碎声或电流中断声 |
| 死亡 / 失败 | 深沉破碎声 |
| 道具掉落拾取 | 清脆"咻"声，音调随道具稀有度/类型变化；连续拾取多个时音调逐级升高 |
| 子弹时间开启 | 标志性激活音效（待定） |
| 子弹时间结束 | 短促收缩音效（待定） |
