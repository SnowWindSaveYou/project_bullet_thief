# 角色左右朝向伪 3D 技术方案

> 用纯 2D NanoVG 绘制实现角色转头时的深度视差效果，无需真正的 3D 投影。

---

## 核心思路

整个系统分为两层，彼此独立叠加：

| 层 | 作用 | 变量 | 值域 |
|----|------|------|------|
| Layer 1 — 左右翻转 | 角色整体镜像 | `char.dir` | `1`（右）/ `-1`（左） |
| Layer 2 — 头部偏转 | 深度视差偏移 | `char.face_yaw` → `fx` | `0` ~ `0.6` → `0` ~ `12` |

**设计关键**：所有身体部件以"面向右"为基准坐标绘制。`dir` 负责整体翻转，`fx` 负责偏转时的深度层级差异。两者互不干扰。

---

## Layer 1：整体左右翻转

### 实现

```lua
-- 绘制入口（CharacterDrawing.lua）
nvgSave(vg)
nvgTranslate(vg, char.x, char.y)
nvgScale(vg, char.dir, 1)   -- dir=1 朝右，dir=-1 镜像朝左
-- ... 绘制所有部件 ...
nvgRestore(vg)
```

### 触发条件

```lua
-- 移动时更新朝向
if move_x ~= 0 then
    char.dir = move_x > 0 and 1 or -1
end
```

- 无平滑过渡，瞬间翻转
- 所有子部件无需额外处理，由矩阵变换统一镜像

## Layer 2：伪 3D 偏转视差

### 核心参数

```lua
-- 驱动值
char.face_target_yaw = 0.6    -- 移动时目标偏转量
char.face_target_yaw = 0.0    -- 静止时回正

-- 每帧插值（dt * 6 ≈ 约 0.1s 过渡时间）
char.face_yaw = lerp(char.face_yaw, char.face_target_yaw, dt * 6)

-- 转换为像素偏移基准（乘以 20）
local fx = char.face_yaw * 20   -- 范围 0 ~ 12
```

| 参数 | 值 | 说明 |
|------|-----|------|
| `face_target_yaw`（移动） | `0.6` | 偏转目标 |
| `face_target_yaw`（静止） | `0.0` | 回正 |
| 插值速率 | `dt * 6` | 约 0.1s 到达目标 |
| `fx` 乘数 | `× 20` | 转换为像素级偏移 |
| `fx` 最大值 | `≈ 12` | 最大偏移像素基准 |

### 原理

不同深度层的部件按不同系数位移 `fx`，模拟视角旋转时的**视差**效果：
- 靠近观察者的部件（前发、发夹）→ 偏移大
- 远离观察者的部件（后发）→ 反方向偏移
- 身体中心部件（躯干、腿）→ 偏移小

---

## 各部件 fx 系数一览表

### 头部区域

| 部件 | 系数 | 方向 | 效果说明 |
|------|------|------|---------|
| 后发 (back hair) | `fx * -0.6` | **反向** | 头后方，转头时反方向移动 |
| 脸颊腮红 (blush) | `fx * 0.35` | 同向 | 脸部表面 |
| 眼睛位置 (eye L/R) | `fx * 0.4` | 同向 | 眼睛整体偏移 |
| 瞳孔注视点 (gaze) | `fx * 0.15` | 同向 | 瞳孔微调，比眼眶偏移小 |
| 嘴巴 (mouth) | `fx * 0.3` | 同向 | 在眼和轮廓之间 |
| 鬓发 (sidelocks) | `fx * 0.5` | 同向 | 侧面，比前发稍近 |
| 前发 (front hair) | `fx * 0.7` | 同向 | 头顶最前层 |

### 身体区域

| 部件 | 系数 | 方向 | 效果说明 |
|------|------|------|---------|
| 脖子 (neck) | `fx * 0.2` | 同向 | 头身连接 |
| 躯干服装 (torso) | `fx * 0.2` | 同向 | 通过 `apply_parallax`（含挤压） |
| 手臂锚点 (arm) | `fx * 0.2` | 向内收拢 | 两臂同时向中线靠拢 |
| 腿部锚点 (leg) | `fx * 0.1` | 向内收拢 | 两腿同时向中线靠拢 |

### 头饰/配件

| 部件 | 系数 | 方向 | 效果说明 |
|------|------|------|---------|
| 发夹 (hairclip) | `fx * 0.9` | 同向 | 最外层，偏移最大 |
| 帽子 (hat) | `fx * 0.6` | 同向 | 头顶偏上 |
| 猫耳 (cat ears) | `fx * 0.5` | 同向 | 头顶两侧 |
| 兔耳 (rabbit ears) | `fx * 0.4` | 同向 | 类似猫耳，稍低 |

## 躯干前倾挤压 (apply_parallax)

除了偏移外，服装还有一个轻微的水平挤压，模拟身体正面角度缩短：

```lua
local function apply_parallax(vg, fx)
    local shift = fx * 0.2
    nvgTranslate(vg, shift * 0.5, 0)               -- 中心微移
    local sx = 1.0 - math.abs(shift) / 85           -- 水平挤压
    if sx > 0.5 then nvgScale(vg, sx, 1.0) end     -- 应用
end
```

| `fx` 值 | `shift` | 中心偏移 | 水平缩放 |
|---------|---------|---------|---------|
| 0 | 0 | 0 | 1.000 |
| 6 | 1.2 | 0.6px | 0.986 |
| 12 | 2.4 | 1.2px | 0.972 |

效果极其微妙（最大缩放仅 ~3%），但搭配偏移一起能提升立体感。

## 手臂/腿部内收模式

手臂和腿部不是单纯偏移，而是**向身体中线收拢**，模拟侧面变窄：

```lua
-- 手臂（CharacterRenderer.lua）
local narrow = ctx.fx * 0.2
local ax = (side < 0) and (-bw + narrow) or (bw - narrow)
-- side < 0 = 左臂（近侧），向右收 narrow 像素
-- side > 0 = 右臂（远侧），向左收 narrow 像素

-- 腿部
local leg_shift = ctx.fx * 0.1
local ox = (side < 0) and (-ls + leg_shift) or (ls - leg_shift)
```

## 没有使用的技术

以下技术在本方案中**刻意未使用**：

- NanoVG 矩阵 skew/shear（剪切变形）
- 真实透视投影矩阵
- 不同部件的缩放差异（仅 apply_parallax 的躯干有微弱缩放）
- Z-index 重排（绘制顺序固定）

整个伪 3D 效果仅依赖：
1. 整体镜像翻转（`nvgScale(dir, 1)`）
2. 逐层水平偏移（不同 `fx` 系数）
3. 躯干微弱水平挤压

## 实现检查清单

移植到其他项目时确认：

- [ ] 角色所有部件统一以"面向右"为基准绘制
- [ ] 用 `nvgScale(dir, 1)` 做整体左右翻转，不要逐部件翻转
- [ ] `face_yaw` 使用 lerp 平滑过渡，不要瞬间跳变
- [ ] 后发/背面元素 `fx` 系数为**负值**（反向移动）
- [ ] 前层元素系数 > 后层元素系数（形成视差）
- [ ] 头饰系数最大、腿脚系数最小
- [ ] 手臂和腿部是"向内收拢"模式，不是单方向偏移
- [ ] 躯干衣服使用 apply_parallax（偏移 + 微弱挤压）

## 参数调试建议

| 想要效果 | 调整方向 |
|---------|---------|
| 更强的转头感 | 增大 `face_target_yaw`（如 0.8）或增大 `× 20` 乘数 |
| 更快转头 | 增大 lerp 速率（如 `dt * 10`） |
| 更夸张的前后层分离 | 拉大前发与后发系数差（如前发 1.0, 后发 -1.0） |
| 更多身体扭转感 | 增大 arm/leg 收拢系数（如 0.4 / 0.2） |
| 更强前倾感 | 增大 apply_parallax 的 `/85` 分母减小（如 `/50`） |
