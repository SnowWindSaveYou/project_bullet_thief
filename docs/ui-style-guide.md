# UI 风格指南 - Bullet Thief

> 本文档为后续新增 UI 组件提供统一的视觉与动效参考。  
> 配色请始终引用 `Theme.lua`，本文档只描述结构规范与动效曲线。

---

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| **暗底亮字** | 深灰蓝背景上使用高对比度亮色文字，确保可读性 |
| **圆角一切** | 面板、按钮、卡片、进度条均使用圆角，无直角元素 |
| **描边定形** | 每个独立元素都有明确描边，让形状在暗底上"立"起来 |
| **弹性动效** | 所有出现/强调使用 easeOutBack/easeOutElastic，消失使用 easeOutCubic |
| **层级分明** | 背景花纹 → 游戏世界 → HUD → 弹窗遮罩 → 弹窗面板 → 扫描线 |

## 2. 组件规范

### 2.1 面板 (Panel)

```
┌─────────────────────────────┐  ← 描边 3px，圆角 12px
│                             │
│      (内容区域)              │  ← 背景半透明深蓝灰
│                             │
└─────────────────────────────┘
  ↓ 投影偏移 (+3px, +4px)，黑色 35% 不透明度
```

- **圆角**: 12px
- **描边**: 3px，淡紫色（可通过 `borderColor` 覆盖为红色等强调色）
- **阴影**: 向右下偏移 (3, 4)px，黑色 alpha 0.35
- **内间距**: 建议内容区域距面板边缘 >= 16px

### 2.2 按钮 (Button)

- **高度**: 38px 固定
- **圆角**: 8px
- **描边**: 2.5px
- **水平内边距**: 20px（文字左右各留）
- **阴影**: 向右下偏移 (2, 3)px

**变体 (Variant)**:

| 变体 | 背景色 | 用途 |
|------|--------|------|
| `primary` | 绿色 | 主要行动（开始、确认） |
| `accent` | 红色 | 强调/危险（退出、删除） |
| `dark` | 深色面板底 | 次要操作 |
| `disabled` | 灰色 | 不可用 |

**Hover 态**:
- 白色叠加层 alpha 0.18 覆盖整个按钮
- 顶部光泽条：上方 35% 高度区域，白色 alpha 0.10

### 2.3 圆形动作按钮 (CircleButton)

- 用于 HUD 操作（攻击、闪避等）
- **结构**: 阴影圆 → 底色圆 → 能量弧(可选) → 图标/文字 → 描边环
- **描边**: 非激活 2px / 激活 2.5px
- **能量弧**: strokeWidth 4px，NVG_ROUND 端帽
- **Hover 态**: 内部白色叠加 0.15 + 外环发光 (r+2, stroke 2px, 白色 0.20)

### 2.4 进度条 (ProgressBar)

- **高度**: 14px（可自定义）
- **圆角**: 4px
- **描边**: 1.5px
- **背景**: 白色 alpha 0.9（使填充色对比鲜明）
- **填充**: 内缩 1px 绘制，避免描边遮挡
- **标签**: 在进度条上方 10px，小号字体左对齐

### 2.5 胶囊徽章 (Badge)

- 圆角 = 高度/2（全圆角胶囊形）
- 高度 16px，水平 padding 6px
- 用于快捷展示数值（轨道子弹数、状态标签）

### 2.6 卡片 (Card)

- **圆角**: 10px
- **描边**: 2.5px
- **Hover 态**: 白色叠加 0.12 + 顶部光泽条 0.08 + 描边加亮
- **选中态**: 棋盘格纹理叠加(8px格子, alpha 0.3)

### 2.7 遮罩 (Overlay)

- 全屏矩形
- 颜色: 深蓝灰色调（从 Theme.colors.overlay 取）
- 默认 alpha: 0.60
- 弹窗出现时先渐入遮罩，再弹入面板

## 3. 图标规范 (矢量绘制)

游戏内图标使用 NanoVG 矢量路径绘制，不依赖外部图片：

| 属性 | 规范 |
|------|------|
| 画布 | 统一在以 (cx, cy) 为中心的范围内绘制 |
| 线宽 | 2.0px 描边（小图标 1.5px） |
| 端帽 | NVG_ROUND（圆头） |
| 连接 | NVG_ROUND |
| 颜色 | 从 Theme 取色或使用 lightText |
| 风格 | 简洁线性图标，1-2 笔路径构成 |

**常用图标参考**:
- 暂停: 两条竖线 `||`
- 播放: 三角形 `▶`
- 返回: 左箭头 `←`
- 关闭: 叉号 `×`
- 设置: 齿轮轮廓

## 4. 动效规范

### 4.1 入场动画（弹窗/面板出现）

采用**级联**模式，每个子元素依次进入：

```
t=0.00  遮罩 fadeIn           easeOutCubic    0.40s
t=0.05  面板 scale 0→1       easeOutBack     0.45s
t=0.15  标题 scale 0→1       easeOutBack     0.40s
t=0.30  内容 fadeIn+slideUp   easeOutCubic    0.35s
t=0.50  底部按钮 fadeIn       easeOutCubic    0.35s
```

- 各元素延迟间隔 0.10~0.15s
- Scale 动画配合 easeOutBack 产生"弹出"感
- 文字/小元素只做 fadeIn + 可选的 slideY

### 4.2 退场动画

- 全部元素同时 fadeOut, duration 0.25s, easeOutCubic
- 面板可选 scale 1→0.9 配合 fadeOut

### 4.3 数值变化弹跳

当 HUD 数值变化时：
- scale 跳到 1.25~1.35
- 回弹 easeOutElastic, duration 0.35~0.40s

### 4.4 Hover 反馈

- **即时**(无 tween): 叠加白色高亮层
- 可选: cursor 附近加微光晕（目前未实装）

### 4.5 按钮按压

- 暂无 press-down 动画（移动端触控为主）
- 未来可加 scale 0.95 的 0.1s 反馈

## 5. 排版

| 用途 | 字号 | 字重 |
|------|------|------|
| 主标题 | 28px | sans (Regular) |
| 副标题 | 18px | sans |
| 正文/按钮 | 14~15px | sans |
| 小标签/徽章 | 10~11px | sans |
| HUD 数字 | 12px | sans |

- 标题带描边阴影（偏移 1.5px/2px, 黑色 0.15）
- 对齐: 标题居中，标签左对齐，数值右对齐

---

## 6. 间距与布局

| 场景 | 间距 |
|------|------|
| 面板内边距 | 16~20px |
| 元素间垂直间距 | 12~16px |
| 按钮组间距 | 10~12px |
| HUD 边缘安全区 | 16px |
| 弹窗居中 | 水平居中，垂直居中偏上 10% |

## 7. 新组件开发检查清单

新增组件时确认：

- [ ] 颜色全部来自 `Theme.lua`，无硬编码 RGB
- [ ] 圆角/描边参数来自 `Theme.panel` / `Theme.button` / `Theme.card`
- [ ] Hover 态使用 `Components.isPointerInRect/Circle` 检测
- [ ] 入场动画使用 Tween 级联模式
- [ ] 阴影偏移遵循 (2~3, 3~4)px 规则
- [ ] 在变换上下文 (nvgTranslate/Scale) 内的按钮需预计算世界坐标做 hover/click
- [ ] 文字使用 `Theme.font.family` 字体
