# VFX & 视觉指示 风格指南

> BulletThief 项目的特效和 UI 指示器视觉规范。
> 所有新增特效/指示必须遵循本文档，确保风格统一。

---

## 1. 总体原则

| 原则 | 说明 |
|------|------|
| **纯矢量** | 所有图形使用 NanoVG 绘制，无位图/贴图 |
| **几何化** | 使用线条、圆弧、圆形等基础几何形状，不使用复杂多边形 |
| **圆角** | 所有线段末端和拐角使用 `NVG_ROUND`（线帽 + 线连接） |
| **轻量** | 特效持续时间短（0.15s ~ 0.55s），快闪快消，不拖泥带水 |
| **渐隐消失** | 特效统一以 alpha 渐隐结束，不使用突然消失 |

---

## 2. 线条粗细规范

粗细是风格一致性的核心。全局遵循以下层级：

| 层级 | 宽度 | 用途 |
|------|------|------|
| **主要** | **3.5** | 玩家核心元素（能量环弧、锁定范围虚线圈） |
| **标准** | **3.0** | 大多数特效（命中火花、回血线条、方向 chevron） |
| **轻量** | **2.5** | 次要特效（擦弹火花、子弹时间呼吸光环） |
| **细线** | **1.5** | 背景/装饰（普通子弹描边、地图边界） |

**规则**：
- 特效衰减时，线宽可从标准逐渐变细，但 **最小值不低于 1.5**
- 新特效默认使用 **3.0**，只有明确理由才偏离
- 公式示例：`math.max(1.5, 3.0 * (1 - t))` — 从 3.0 开始，随生命周期衰减

## 3. 色彩体系

### 3.1 语义色板

| 语义 | RGB | nvgRGBAf | 用途 |
|------|-----|----------|------|
| **玩家/正面** | `(100, 220, 255)` | `(0.39, 0.86, 1.0)` | 命中敌人、能量弧、擦弹 |
| **敌方/危险** | `(255, 80, 80)` | `(1.0, 0.31, 0.31)` | 玩家受伤闪光 |
| **可夺取子弹** | `(242, 102, 26)` | `(0.95, 0.4, 0.1)` | 橙色敌方子弹 |
| **子弹时间高亮** | `(255, 230, 77)` | `(1.0, 0.9, 0.3)` | BT 中可夺取子弹呼吸环 |
| **回血/增益** | `(80, 220, 100)` | `(0.31, 0.86, 0.39)` | 回血上升线条 |
| **瞄准/开火** | `(255, 230, 51)` | `(1.0, 0.9, 0.2)` | 开火时瞄准虚线 |
| **中性/指示** | `(255, 255, 255)` | `(1.0, 1.0, 1.0)` | 方向 chevron 箭头 |
| **全屏闪光** | `(200, 240, 255)` | `(0.78, 0.94, 1.0)` | 子弹时间激活闪白 |
| **擦弹亮白** | `(180, 240, 255)` | `(0.71, 0.94, 1.0)` | 擦弹火花（比主青更白） |

### 3.2 颜色使用原则

- **不使用纯黑描边**（与背景融合不明显）
- **特效颜色与触发语义绑定**：打中敌人=青，被打=红，回血=绿
- **同一特效内不混用多色**（单色 + alpha 变化营造层次）
- **全屏效果使用极低 alpha**（≤ 0.35），避免遮挡游戏画面

## 4. 时间与动画规范

### 4.1 持续时间

| 特效类型 | 持续时间 | 说明 |
|---------|----------|------|
| 命中爆发 (hit) | **0.25s** | 环 + 火花 |
| 擦弹火花 (graze) | **0.18s** | 极短，一闪即逝 |
| 全屏闪光 (flash) | **~0.14s** | alpha 0.35 以 2.5/s 衰减 |
| 回血上升 (heal) | **0.55s** | 最长特效，含错时延迟 |
| 呼吸脉冲 (pulse) | **持续循环** | sin 波，频率 10 Hz |

### 4.2 动画曲线

| 属性 | 曲线 | 说明 |
|------|------|------|
| 扩张（半径增大） | `easeOutQuad` | 快速展开，末尾减速 |
| 渐隐（alpha 减小） | `linear` 或 `easeInQuad` | 均匀消失或加速消失 |
| 线段缩短 | 指数衰减 `len * (1 - dt * K)` | 自然收缩 |
| 呼吸/脉动 | `sin(time * freq)` | 连续柔和循环 |

### 4.3 错时生成 (Stagger)

多个粒子的特效使用错时延迟，避免同时出现的机械感：
```
delay = (index - 1) * 0.04 + random * 0.03
```
- 基础间隔：0.03 ~ 0.05s
- 随机抖动：± 0.03s

## 5. 几何形状规范

### 5.1 方向指示器

**常驻 Chevron（V 形箭头）**：
- 形状：开口朝前的 V 形折线（非实心三角）
- 臂长：8px
- 张角：`π * 0.75`（135°）
- 线宽：3.0
- 线帽/线连接：`NVG_ROUND`
- 距玩家中心：`radius + 20`
- alpha：待机 0.45 / 开火 0.9

**开火瞄准线（叠加态）**：
- 胶囊段虚线（dash 14, gap 9, width 5）
- 线帽：`NVG_ROUND`（形成胶囊形）
- 颜色：黄色 `(1.0, 0.9, 0.2, 0.7)`
- 末端：胶囊箭头

### 5.2 爆发粒子

**径向火花线**：
- 数量：5 ~ 7 根
- 均匀分布 + 随机角度偏移 ±0.3 rad
- 初始长度：12 ~ 22px（按 scale）
- 运动：径向外扩，速度 120 ~ 200 px/s
- 缩短：每帧 `len * (1 - dt * 6)`

**擦弹火花**：
- 数量：3 ~ 5 根
- 方向：垂直于子弹-玩家连线（两侧交替）
- 长度：6 ~ 11px
- 速度：80 ~ 140 px/s

### 5.3 圆环/弧线

- **扩散环**：从小半径扩展到大半径，线宽递减
  - 起始：4px 半径
  - 终止：28px 半径（× scale）
- **能量环**：固定半径弧线，线宽 3.5
- **呼吸光环**：半径 = 基础 + sin 波偏移（±3px）

### 5.4 上升线条（回血）

- 纯竖直线段（无弧度）
- 长度：10 ~ 18px，随时间缩短 40%
- 水平散布：角色宽度 × 0.9 范围内
- 上升速度：60 ~ 100 px/s
- 水平漂移：±15 px/s（轻微）
- 淡入：前 20% 时间 alpha 从 0→1

## 6. 透明度规范

| 场景 | alpha 值 |
|------|----------|
| 全屏覆盖（flash） | ≤ 0.35 |
| 特效峰值 | 0.8 ~ 1.0（通过 nvgRGBA 的 180~220） |
| 待机指示器 | 0.4 ~ 0.5 |
| 激活指示器 | 0.85 ~ 0.95 |
| 背景装饰描边 | 0.3 ~ 0.5 |

---

## 7. 新增特效 Checklist

添加新特效前，逐项对照：

- [ ] **线帽** 是否设为 `NVG_ROUND`？
- [ ] **线宽** 是否在 2.5 ~ 3.5 范围内？衰减最小值 ≥ 1.5？
- [ ] **颜色** 是否使用语义色板中的对应颜色？
- [ ] **持续时间** 是否在 0.15s ~ 0.6s 范围内（持续循环除外）？
- [ ] **消失方式** 是否为 alpha 渐隐？
- [ ] **粒子数量** 是否适度（3~7 个）？过多会显得杂乱
- [ ] **形状** 是否只用了线段、圆弧、圆形？未引入复杂多边形？
- [ ] **对象池** 是否使用 Pool 回收，避免 GC 压力？
- [ ] **跟随目标** 移动物体的特效是否存储 target 引用而非固定坐标？

## 8. 反面示例（避免）

| 不要 | 原因 | 应该 |
|------|------|------|
| 实心三角箭头 | 与圆角风格冲突 | 使用 ROUND chevron 折线 |
| 线宽 < 1.5 | 高 DPI 屏几乎不可见 | 最小 1.5 |
| 线宽 > 5.0 | 过于粗重，与 3.5 主线条不协调 | 最大 5.0（仅胶囊虚线） |
| 方形线帽 `NVG_BUTT` | 锐角突兀 | 统一 `NVG_ROUND` |
| 多色混合单一特效 | 视觉杂乱 | 单色系 + alpha 变化 |
| 特效 > 1s | 拖沓，干扰游戏节奏 | 保持 0.5s 以内 |
| 固定坐标粒子 | 无法跟随移动角色 | 存储 target 引用 |
| 纯白 alpha=1.0 大面积 | 刺眼 | 全屏效果 ≤ 0.35 |

## 9. 持续性攻击特效（激光/光束）

激光类特效是**持续性**效果，不属于"快闪快消"瞬时特效，但仍需遵循核心风格原则。

### 9.1 蓄力预警线

| 属性 | 值 | 说明 |
|------|-----|------|
| 形状 | 虚线段 | 与瞄准线统一使用胶囊虚线 |
| dash / gap | 10 / 7 | 略短于玩家瞄准线(14/9)，区分友敌 |
| 线宽 | **2.5** | 轻量层级 |
| 线帽 | `NVG_ROUND` | 圆头 = 胶囊段 |
| 颜色 | `(1.0, 0.2, 0.1)` | 红系，表达危险 |
| alpha | `0.3 + 0.5 * chargeT` | 随蓄力进度从淡→浓 |
| 长度 | `60 + 240 * chargeT` px | 逐渐延伸至射程 60% |

### 9.2 激光射线（三层结构）

光束使用三层叠加模拟辉光效果：

| 层级 | 宽度 | alpha | 颜色 | 作用 |
|------|------|-------|------|------|
| 外层光晕 | `width × 3.0` | 0.25 | `(0.8, 0.1, 0.0)` | 弥散辉光 |
| 中层主体 | `width × 1.5` | 0.70 | `(0.9, 0.15, 0.05)` | 可见光束 |
| 内层核心 | `width × 0.5` | 0.90 | `(1.0, 0.6, 0.4)` | 高亮中心 |

所有层统一：`NVG_ROUND` 线帽 + `flicker` 闪烁（sin 30Hz）+ 最后 20% 时间 fadeAlpha 衰减。

### 9.3 激光敌人身体

| 属性 | 值 | 说明 |
|------|-----|------|
| 身体形状 | 正六边形 | 几何化 |
| 描边线宽 | 1.5 | 细线层级（身体本体不需粗线） |
| 描边线连接 | `NVG_ROUND` | 圆角连接，避免尖角 |
| 核心圆 | 蓄力时脉冲放大 | 大小 0.4r → 0.65r |
| 核心颜色 | 随状态变色 | idle 红、charging 橙闪、firing 亮红 |
| 蓄力粒子 | 8 个小圆点收缩 | 填充圆（几何基元），半径 3~5px |

### 9.4 AOE 爆炸（Mortar Explosion）

炮弹落地触发的范围爆炸，持续 0.5s，由六层叠加构成：

| 层 | 内容 | 关键参数 |
|----|------|----------|
| 1 | 残留焦痕虚线环 | 10 段弧，`NVG_ROUND`，`(60,30,5)` 暗棕 |
| 2 | 冲击波虚线环 | 10 段弧，ease-out 扩张，亮橙描边 |
| 3 | 放射爆裂线 | 8~11 根短线从中心射出，星爆感 |
| 4 | 双层中心闪光 | 前 30%：外层橙色径向渐变光晕 + 内层白热核心 |
| 5 | 余烬粒子 | 10~15 个双层圆点（辉光 + 亮核），无描边 |
| 6 | 外圈径向渐变辉光 | `nvgRadialGradient`，半径 × 1.2 |

**冲击波环规范**：

| 属性 | 值 |
|------|-----|
| 形状 | 虚线弧段环（10 段，gapRatio 0.35，带轻微旋转） |
| 线帽 | `NVG_ROUND` |
| 线宽 | `max(1.5, 3.5 * (1 - t))`（主要层级，随时间衰减） |
| 描边色 | `(255, 180, 50)` 亮橙 |
| 扩张 | ease-out 至 `radius`，系数 2.2 |

**放射爆裂线规范**：

| 属性 | 值 |
|------|-----|
| 数量 | 8~11 根，均匀分布 + 随机偏移 |
| 线帽 | `NVG_ROUND` |
| 线宽 | `max(1.5, 3.0 * (1 - t * 0.7))` |
| 颜色 | `(255, 210, 80)` 亮金 |
| 运动 | 初始速度 180~280，阻力 0.92 快速减速 |
| 线长 | 20~45，随时间缩短 `len * max(0.2, 1 - t*1.5)` |

**余烬粒子规范**：

| 属性 | 值 |
|------|-----|
| 形状 | 纯圆点（**无描边、无多边形**） |
| 渲染 | 双层：外层辉光（× 2.2 半径，alpha 60）+ 内层亮核（alpha 220） |
| 颜色 | 白热→亮橙→暗红 `lerp(255→200, 200→50, 80→10)` |
| 大小衰减 | `size * max(0.3, 1 - t * 0.8)` |
| 运动 | 径向外扩 + 重力 260 px/s² + X 阻力 0.94 + Y 阻力 0.97 |

**中心闪光规范**：

| 属性 | 值 |
|------|-----|
| 持续 | 前 30% 时间 |
| 外层光晕 | 径向渐变 `(255,140,30)` → 透明，半径 18→48 |
| 内层核心 | 实心圆 `(255,245,220)`，半径 8→18 |
| 淡出 | `easeInQuad` 加速消失 |

### 9.5 抛物线炮弹（Mortar）

**弹体**：菱形（drawDiamond），根据抛物高度向上偏移，模拟空中飞行。

| 属性 | 值 | 说明 |
|------|-----|------|
| 弹体形状 | 菱形（4 顶点） | 几何化，区别于圆形普通子弹 |
| 填充色 | `(0.8, 0.5, 0.1)` | 深橙，归属敌方色系 |
| 描边色 | `(1.0, 0.7, 0.2, 0.6)` | 金橙高亮 |
| 描边线宽 | 1.5 | 细线层级 |
| 描边线连接 | `NVG_ROUND` | 圆角连接 |

**落点预警圈**：虚线段圆环 + 半透明填充，随落地进度增大增强。

| 属性 | 值 | 说明 |
|------|-----|------|
| 形状 | 虚线段弧圈（12 段） | 与锁定范围圈/激光预警统一 |
| 间隙比 | 35% | 弧段占 65%，间隙 35% |
| 线宽 | **2.5** | 轻量层级 |
| 线帽 | `NVG_ROUND` | 胶囊圆头 |
| 颜色 | `(0.9, 0.4, 0.1)` | 橙色危险色 |
| alpha | `0.2 + landProgress * 0.5` | 远时淡、近时浓 |
| 半径 | `aoeRadius × (0.3 + progress × 0.7)` | 随落地进度扩张 |
| 脉冲 | `sin(time * (6 + progress * 10))` | 接近落地脉冲加速 |
| 填充 | 同色，alpha × 0.15 × pulse | 极淡底色烘托范围 |
